# FROST POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser-only proof-of-concept that reproduces the FROST paper's core primitive — timed random reads against an OPFS probe file to visualize live SSD-contention latency — served by a zero-dependency Node server that sets the cross-origin-isolation headers the high-resolution timer requires.

**Architecture:** A small Node `http` server serves static files from `public/` and adds COOP/COEP headers to every response. The page (`public/`) orchestrates UI, controls, and a live canvas chart. A Web Worker (`public/probe-worker.js`) owns all synchronous OPFS disk I/O and timing, posting sample batches to the page. Pure logic (ring buffer, stats, spike filter) lives in `src/` ES modules shared by both the browser and `node --test`.

**Tech Stack:** Node 23 (built-in `http`, `fs`, `node --test`, `fetch`), vanilla browser JS (ES modules), OPFS `createSyncAccessHandle`, Web Workers, Canvas 2D. No third-party dependencies.

```js
export class RingBuffer {
  constructor(capacity) {
    this._cap = capacity;
    this._buf = new Array(capacity);
    this._start = 0;
    this._len = 0;
  }

  get capacity() { return this._cap; }
  get length() { return this._len; }

  push(value) {
    const end = (this._start + this._len) % this._cap;
    this._buf[end] = value;
    if (this._len < this._cap) {
      this._len++;
    } else {
      this._start = (this._start + 1) % this._cap;
    }
  }

  pushAll(values) {
    for (const v of values) this.push(v);
  }

  toArray() {
    const out = new Array(this._len);
    for (let i = 0; i < this._len; i++) {
      out[i] = this._buf[(this._start + i) % this._cap];
    }
    return out;
  }
}
```

```js
export function median(values) {
  if (values.length === 0) return NaN;
  const s = [...values].sort((a, b) => a - b);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 ? s[mid] : (s[mid - 1] + s[mid]) / 2;
}

// Nearest-rank percentile. p in [0, 100].
export function percentile(values, p) {
  if (values.length === 0) return NaN;
  const s = [...values].sort((a, b) => a - b);
  if (p <= 0) return s[0];
  if (p >= 100) return s[s.length - 1];
  const rank = Math.ceil((p / 100) * s.length);
  return s[Math.min(rank, s.length) - 1];
}
```

`src/spike-filter.js`:
```js
// Replace every sample greater than thresholdMs with the mean of up to `window`
// surrounding non-spike samples (half the window on each side). If no non-spike
// neighbor is in range, fall back to the threshold value.
export function spikeFilter(samples, { thresholdMs = 1, window = 100 } = {}) {
  const half = Math.max(1, Math.floor(window / 2));
  const out = samples.slice();
  for (let i = 0; i < samples.length; i++) {
    if (samples[i] <= thresholdMs) continue;
    let sum = 0;
    let count = 0;
    const lo = Math.max(0, i - half);
    const hi = Math.min(samples.length - 1, i + half);
    for (let j = lo; j <= hi; j++) {
      if (j === i) continue;
      if (samples[j] > thresholdMs) continue;
      sum += samples[j];
      count++;
    }
    out[i] = count > 0 ? sum / count : thresholdMs;
  }
  return out;
}
```

```js
import http from 'node:http';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const PUBLIC_DIR = path.join(__dirname, 'public');

const MIME = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.svg': 'image/svg+xml',
  '.ico': 'image/x-icon',
};

export function contentTypeFor(filePath) {
  return MIME[path.extname(filePath).toLowerCase()] || 'application/octet-stream';
}

function setIsolationHeaders(res) {
  res.setHeader('Cross-Origin-Opener-Policy', 'same-origin');
  res.setHeader('Cross-Origin-Embedder-Policy', 'require-corp');
}

export function createFrostServer(publicDir = PUBLIC_DIR) {
  return http.createServer((req, res) => {
    setIsolationHeaders(res);

    const urlPath = decodeURIComponent(new URL(req.url, 'http://x').pathname);
    const rel = urlPath === '/' ? 'index.html' : urlPath.replace(/^\/+/, '');
    const resolved = path.resolve(publicDir, rel);

    if (resolved !== publicDir && !resolved.startsWith(publicDir + path.sep)) {
      res.writeHead(403); res.end('Forbidden'); return;
    }

    fs.readFile(resolved, (err, data) => {
      if (err) { res.writeHead(404); res.end('Not Found'); return; }
      res.writeHead(200, { 'Content-Type': contentTypeFor(resolved) });
      res.end(data);
    });
  });
}

const isMain = process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1]);
if (isMain) {
  const port = Number(process.env.PORT) || 8080;
  createFrostServer().listen(port, () => {
    console.log(`FROST POC on http://localhost:${port}  (crossOriginIsolated enabled)`);
  });
}
```

### Task 5: OPFS measurement worker

The Web Worker owns all synchronous OPFS I/O: provision the probe file, fill it with random data, then loop timed random reads and post sample batches. Not unit-tested (requires real OPFS + SSD); verified via the manual checklist in Task 8.

**Files:**
- Create: `public/probe-worker.js`

- [ ] **Step 1: Write the worker**

`public/probe-worker.js`:
```js
// FROST OPFS measurement engine. Runs in a Web Worker because
// createSyncAccessHandle() and its read/write are synchronous.

const FILE_NAME = 'frost-probe.bin';
const FILL_CHUNK = 8 * 1024 * 1024; // 8 MiB
const BATCH_MS = 16;                // flush samples to the page ~60x/sec

let handle = null;
let running = false;

function post(type, payload = {}) { self.postMessage({ type, ...payload }); }

async function openHandle() {
  const root = await navigator.storage.getDirectory();
  const fh = await root.getFileHandle(FILE_NAME, { create: true });
  return fh.createSyncAccessHandle();
}

function makeRandomChunk() {
  const chunk = new Uint8Array(FILL_CHUNK);
  // getRandomValues caps at 65536 bytes per call.
  for (let off = 0; off < chunk.length; off += 65536) {
    crypto.getRandomValues(chunk.subarray(off, Math.min(off + 65536, chunk.length)));
  }
  return chunk;
}

async function provision(sizeBytes) {
  handle = await openHandle();
  if (handle.getSize() === sizeBytes) {
    post('status', { phase: 'ready', message: 'Reusing existing probe file.' });
    return;
  }
  handle.truncate(sizeBytes);
  const chunk = makeRandomChunk();
  let written = 0;
  while (written < sizeBytes) {
    const n = Math.min(FILL_CHUNK, sizeBytes - written);
    // Mutate a few offset-dependent bytes so blocks are not identical (defeats dedup).
    chunk[0] = written & 0xff;
    chunk[1] = (written >> 8) & 0xff;
    chunk[2] = (written >> 16) & 0xff;
    handle.write(chunk.subarray(0, n), { at: written });
    written += n;
    post('fillProgress', { written, total: sizeBytes });
  }
  handle.flush();
  post('status', { phase: 'ready', message: 'Probe file ready.' });
}

function measureLoop(sizeBytes, readSize) {
  const buf = new Uint8Array(readSize);
  const maxOffset = Math.max(0, sizeBytes - readSize);
  let batch = [];
  let lastFlush = performance.now();

  function tick() {
    if (!running) return;
    // Run a burst of reads, then yield so messages can flush.
    for (let i = 0; i < 64 && running; i++) {
      const offset = Math.floor(Math.random() * (maxOffset / readSize)) * readSize;
      const t0 = performance.now();
      handle.read(buf, { at: offset });
      const dt = performance.now() - t0;
      batch.push(dt);
    }
    const now = performance.now();
    if (now - lastFlush >= BATCH_MS && batch.length) {
      post('samples', { latencies: batch });
      batch = [];
      lastFlush = now;
    }
    setTimeout(tick, 0);
  }
  tick();
}

self.onmessage = async (e) => {
  const msg = e.data;
  try {
    if (msg.type === 'start') {
      post('status', { phase: 'provisioning', message: 'Preparing probe file…' });
      await provision(msg.sizeBytes);
      running = true;
      post('status', { phase: 'measuring', message: 'Measuring SSD contention…' });
      measureLoop(msg.sizeBytes, msg.readSize);
    } else if (msg.type === 'stop') {
      running = false;
      post('status', { phase: 'stopped', message: 'Stopped.' });
    } else if (msg.type === 'delete') {
      running = false;
      if (handle) { try { handle.close(); } catch {} handle = null; }
      const root = await navigator.storage.getDirectory();
      await root.removeEntry(FILE_NAME).catch(() => {});
      post('status', { phase: 'deleted', message: 'Probe file deleted.' });
    }
  } catch (err) {
    running = false;
    post('error', { message: String(err && err.message || err) });
  }
};
```

```js
import { RingBuffer } from '../src/ring-buffer.js';
import { median, percentile } from '../src/stats.js';
import { spikeFilter } from '../src/spike-filter.js';

const CAPACITY = 4000;        // samples kept for the chart
const CAP_GB = 8;             // hard file-size cap
const SPIKE_MS = 1;

const $ = (id) => document.getElementById(id);
const raw = new RingBuffer(CAPACITY);
let worker = null;
let spikeCount = 0;
let sampleCount = 0;
let lastRateStamp = performance.now();
let lastRateCount = 0;
let rate = 0;

function setStatus(text) { $('status').textContent = text; }

function fmtBytes(b) {
  const gb = b / (1024 ** 3);
  return gb >= 1 ? `${gb.toFixed(2)} GB` : `${(b / (1024 ** 2)).toFixed(0)} MB`;
}

async function showEnvironment() {
  $('coi').textContent = self.crossOriginIsolated ? 'yes' : 'NO';
  $('coi').className = self.crossOriginIsolated ? 'ok' : 'bad';
  $('mem').textContent = navigator.deviceMemory ? `${navigator.deviceMemory} GB` : 'unknown';
  const opfsOk = !!(navigator.storage && navigator.storage.getDirectory);
  $('opfs').textContent = opfsOk ? 'yes' : 'NO';
  $('opfs').className = opfsOk ? 'ok' : 'bad';
  try {
    const est = await navigator.storage.estimate();
    $('quota').textContent = `${fmtBytes(est.usage || 0)} used / ${fmtBytes(est.quota || 0)} quota`;
  } catch { $('quota').textContent = 'unavailable'; }
}

function cacheWarning(sizeBytes) {
  const memGB = navigator.deviceMemory;
  if (!memGB) return '';
  const fileGB = sizeBytes / (1024 ** 3);
  if (fileGB < memGB * 1.5) {
    return `⚠ File (${fileGB.toFixed(1)} GB) may fit in the page cache on this ` +
           `~${memGB} GB machine; the SSD signal could be weak. Consider a larger file.`;
  }
  return '';
}

function startWorker(sizeBytes, readSize) {
  worker = new Worker('./probe-worker.js', { type: 'module' });
  worker.onmessage = (e) => {
    const m = e.data;
    if (m.type === 'status') setStatus(m.message);
    else if (m.type === 'fillProgress') {
      const pct = ((m.written / m.total) * 100).toFixed(0);
      setStatus(`Preparing probe file… ${pct}% (${fmtBytes(m.written)} / ${fmtBytes(m.total)})`);
    } else if (m.type === 'samples') {
      for (const v of m.latencies) {
        raw.push(v);
        sampleCount++;
        if (v > SPIKE_MS) spikeCount++;
      }
    } else if (m.type === 'error') {
      setStatus(`Error: ${m.message}`);
      stop();
    }
  };
  worker.postMessage({ type: 'start', sizeBytes, readSize });
}

function stop() {
  if (worker) worker.postMessage({ type: 'stop' });
  $('start').disabled = false;
  $('stop').disabled = true;
}

function updateStats() {
  const arr = raw.toArray();
  const now = performance.now();
  if (now - lastRateStamp >= 1000) {
    rate = Math.round((sampleCount - lastRateCount) * 1000 / (now - lastRateStamp));
    lastRateStamp = now; lastRateCount = sampleCount;
  }
  const last = arr.length ? arr[arr.length - 1] : NaN;
  $('cur').textContent = isNaN(last) ? '—' : `${last.toFixed(3)} ms`;
  $('median').textContent = arr.length ? `${median(arr).toFixed(3)} ms` : '—';
  $('p95').textContent = arr.length ? `${percentile(arr, 95).toFixed(3)} ms` : '—';
  $('rate').textContent = `${rate} /s`;
  $('spikes').textContent = String(spikeCount);
}

function drawChart() {
  const c = $('chart');
  const ctx = c.getContext('2d');
  const w = c.width, h = c.height;
  ctx.clearRect(0, 0, w, h);
  const arr = raw.toArray();
  if (arr.length < 2) { requestAnimationFrame(loop); return; }

  const smooth = spikeFilter(arr, { thresholdMs: SPIKE_MS, window: 100 });
  const maxY = Math.max(0.5, ...smooth) * 1.1;
  const x = (i) => (i / (arr.length - 1)) * w;
  const y = (v) => h - Math.min(v, maxY) / maxY * h;

  // raw trace (faint)
  ctx.strokeStyle = 'rgba(120,170,255,0.35)';
  ctx.beginPath();
  arr.forEach((v, i) => i ? ctx.lineTo(x(i), y(v)) : ctx.moveTo(x(i), y(v)));
  ctx.stroke();

  // smoothed trace (bright)
  ctx.strokeStyle = '#5cf';
  ctx.lineWidth = 1.5;
  ctx.beginPath();
  smooth.forEach((v, i) => i ? ctx.lineTo(x(i), y(v)) : ctx.moveTo(x(i), y(v)));
  ctx.stroke();

  // y-axis label
  ctx.fillStyle = '#9ab';
  ctx.font = '11px monospace';
  ctx.fillText(`${maxY.toFixed(2)} ms`, 4, 12);
  ctx.fillText('0 ms', 4, h - 4);

  requestAnimationFrame(loop);
}

function loop() { updateStats(); drawChart(); }

function init() {
  showEnvironment();
  const sizeInput = $('size');
  const updateWarn = () => {
    const bytes = Number(sizeInput.value) * (1024 ** 3);
    $('sizeLabel').textContent = `${sizeInput.value} GB`;
    $('warn').textContent = cacheWarning(bytes);
  };
  sizeInput.addEventListener('input', updateWarn);
  updateWarn();

  $('start').addEventListener('click', () => {
    if (!self.crossOriginIsolated) {
      setStatus('Not cross-origin isolated — high-resolution timer unavailable. ' +
                'Serve via the included server.js so COOP/COEP headers are set.');
      return;
    }
    const gb = Math.min(CAP_GB, Math.max(1, Number(sizeInput.value)));
    const bytes = gb * (1024 ** 3);
    if (!confirm(`This will create a ${gb} GB file on your disk (deletable afterwards). Continue?`)) return;
    const readSize = Number($('readSize').value);
    spikeCount = 0; sampleCount = 0; lastRateCount = 0;
    $('start').disabled = true; $('stop').disabled = false;
    startWorker(bytes, readSize);
  });

  $('stop').addEventListener('click', stop);

  $('delete').addEventListener('click', () => {
    if (!worker) worker = new Worker('./probe-worker.js', { type: 'module' });
    worker.postMessage({ type: 'delete' });
    setTimeout(showEnvironment, 500);
  });

  requestAnimationFrame(loop);
}

init();
```

````markdown
# FROST POC

Browser-only proof-of-concept of **FROST: Fingerprinting Remotely using OPFS-based SSD
Timing** (Weissteiner et al.). It creates a large file in the Origin Private File System
(OPFS), performs timed random reads against it, and plots the SSD access-latency trace live.
When other activity on the machine touches the same SSD, contention raises the read latencies
— visible as spikes in the trace.

Everything runs locally in your browser. No data leaves the page; there is no backend storage.

## Run

```bash
npm start          # serves http://localhost:8080
PORT=3000 npm start
```

The server sets `Cross-Origin-Opener-Policy: same-origin` and
`Cross-Origin-Embedder-Policy: require-corp` on every response. These enable
`crossOriginIsolated`, which unlocks the high-resolution `performance.now()` timer the
measurement needs. Opening the files directly (`file://`) will NOT work.

## Test

```bash
npm test           # runs the pure-logic unit tests via node --test
```

Unit tests cover the ring buffer, statistics, and spike filter. The timing/OPFS/canvas parts
are hardware-dependent and verified with the manual checklist below.

## Manual test checklist

1. `npm start`, open `http://localhost:8080`. Confirm **Cross-origin isolated: yes** and
   **OPFS available: yes** in the Environment panel.
2. Pick a file size larger than your free RAM (heed the cache warning), click **Start**, accept
   the confirmation. Watch "Preparing probe file… N%" complete.
3. A baseline latency trace appears and updates live.
4. Launch a native app (or load a heavy website) on the same disk. Observe latency spikes in
   the trace and the **spikes >1ms** counter rising.
5. Click **Stop** — the trace freezes. Click **Delete probe file** — the Storage line drops.

## Deployment (frost.moosha.org)

Run `server.js` behind your TLS terminator. The COOP/COEP headers must reach the browser
unmodified, so if a reverse proxy or CDN sits in front, ensure it does not strip them.

## Scope

This POC implements the paper's core measurement primitive and live visualization only. The
CNN fingerprinting and covert-channel constructions from the paper are intentionally out of
scope.
````
